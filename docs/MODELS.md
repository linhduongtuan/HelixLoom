# Model files

Some analyses need files that belong to other people's projects: trained networks, example data. HelixLoom does not carry
them inside the program or this repository when their authors have not said that they may be passed on. The program looks
for them on the computer instead, and says so in the window when they are missing.

## Where the program looks

In this order, the first folder that has the file wins:

1. the folder named by the environment variable `HELIXLOOM_MODELS`;
2. the `models` folder inside the program's settings folder
   (macOS `~/Library/Application Support/HelixLoom/models`, Linux `~/.config/helixloom/models`,
   Windows `%APPDATA%\HelixLoom\models`);
3. for a program built from its source folder, that folder's `assets`.

Inside each of them a group of files has a folder of its own, for example `phylocnn/`.

On a workstation (`helixloom serve`) the same places are searched on the workstation, so install the files there too.

## Installing

Either copy the files into the folder by hand, or open the window that needs them (Tools → PhyloCNN Epidemic Estimates)
and press **Install from folder…**: choose a folder that holds the files (or a folder that has the group's folder in it)
and they are copied into the second place above.

## What is there so far

| Group | Files | What they are | Status |
|-------|-------|---------------|--------|
| `phylocnn` | `Trained_2Generation_PhyDyn.bin`, `…_BD.bin`, `…_BDEI.bin`, `…_BDSS.bin`, `…_PhyDyn_HIV.bin`, `…_BDSS_HIV.bin` | The trained networks of PhyloCNN (Perez & Gascuel 2025), converted from Keras to a plain binary file that HelixLoom reads | **Not in this repository.** The PhyloCNN repository has no licence file, so they may not be passed on without the authors' permission. |
| `phylocnn` | `ZurichHIV-tree.nwk` | The 200-sequence HIV-1 tree of Rasmussen et al. (2017), as shipped in the PhyloCNN repository | Same. Without it the window's example is a made-up tree of 200 tips. |

Everything else that ships with HelixLoom (the demo plasmid, reads, trace, tree; the ubiquitin structure 1UBQ from the Protein
Data Bank; the restriction enzyme table from REBASE) is either generated by the program or public data, and is listed in
`CREDITS.md`.

## Adding a model later

A new model (a motif or domain finder, an epitope or paratope predictor, a language model) should be one more group:
a folder name, the file names, and a note of where it came from and under what licence. Keep the weights out of the
repository unless the licence allows passing them on, and check any download against a published checksum.
